📌 Sobre o projeto

Este projeto foi desenvolvido como atividade do curso de Desenvolvimento de Sistemas (DS).

A empresa de marketing TudoWeb deseja realizar uma pesquisa de opinião com seus clientes para identificar o grau de satisfação com o atendimento prestado.

O programa realiza uma pesquisa com 50 entrevistados, solicitando:

👤 Nome
🎂 Idade
⭐ Opinião sobre o atendimento

As opções de atendimento são:

EXCELENTE
BOM
RUIM

Ao final da pesquisa, o programa apresenta a quantidade de respostas EXCELENTE e RUIM.
